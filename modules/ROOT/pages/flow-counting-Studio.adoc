== Counting the Flows of Your Project

. In Studio, select your project to know the number of billable flows it has.
. On the menu, click the *Flow Count* icon image:flow-count-icon.png[""].
+
Studio displays the number if billable flows your Anypoint Platform Organization is charged for running deployed flows.

image:flow-count.png["A table displaying the flow names and the type of flows that are billable."]

. Click *OK* to close the window.
