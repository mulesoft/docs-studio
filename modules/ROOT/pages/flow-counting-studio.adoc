== Counting the Flows of Your Project in Studio

. Select your project.
. Click the *Flow Count* icon (image:flow-count-icon.png[2,2%""]) in the task bar.
+
Studio displays the number if billable flows your Anypoint Platform Organization is charged for running deployed flows.
+
image:flow-count.png["A table displays the billable flow names and type."]
+
. Click *OK* to close the window.
